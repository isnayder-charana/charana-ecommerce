# apps/web

Tienda CharanaTech en Next.js 16 + Tailwind v4 (se despliega en Vercel).

```bash
pnpm --filter @charanatech/web dev        # http://localhost:3001
pnpm --filter @charanatech/web typecheck
pnpm --filter @charanatech/web build
```
